Engineering Problem Solving

Key Challenges & Technical Solutions

Technical bottlenecks resolved during the cross-platform development lifecycle.

01 · Cross-Platform Typography & Sizing

Challenge: Layout shift and text clipping occurred when rendering custom font metrics across varying Android and iOS pixel densities.

Solution: Engineered a centralized responsive scaling utility using `PixelRatio.roundToNearestPixel()` and standardized design tokens for padding, font sizes, and card borders.

02 · Slot Concurrency & Race Conditions

Challenge: Multiple users selecting the same high-demand weekend wash slot simultaneously caused validation errors at final submission.

Solution: Implemented temporary slot reservations with a 5-minute checkout countdown, alongside optimistic UI updates and immediate slot lock polling.

03 · Firebase Session Resilience

Challenge: Native app process kills by the mobile OS caused intermittent credential drops and unnecessary login prompts on relaunch.

Solution: Integrated `onAuthStateChanged` listeners connected to encrypted local storage to silently hydrate user credentials before screen mounting.

04 · Offline Network State Handling

Challenge: Intermittent cellular connectivity while driving near stations resulted in frozen network loaders.

Solution: Built NetInfo listeners with informative offline status banners, local station cache fallback, and retry queues for network operations.
