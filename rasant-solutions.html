Engineering Problem Solving

Key Challenges & Technical Solutions

Real architectural bottlenecks solved during the development lifecycle.

01 · Real-Time Communication

Challenge: Traditional polling caused high database load and excessive HTTP handshakes, while full WebSockets added unnecessary infrastructure complexity for one-way alert streaming.

Solution: Implemented Server-Sent Events (SSE) via Django streaming HTTP responses. Created client-side auto-reconnection logic and Pinia message caching for zero-latency updates.

02 · Financial Data Integrity

Challenge: Concurrent adjustments to payroll variables (bonuses, leave deductions, tax brackets) risked race conditions and dirty writes during batch disbursement.

Solution: Enforced atomic database transactions (`transaction.atomic()`) with row-level locks on contract tables in MySQL, ensuring calculation consistency before slip generation.

03 · Cross-Origin & Token Expiration

Challenge: Token expiration during long administrator shifts caused API call drops and data loss in unfinished form submissions.

Solution: Configured Axios response interceptors with automatic JWT silent refresh mechanisms that queue pending requests and replay them seamlessly upon token renewal.

04 · Jira Webhook High Volume

Challenge: Bulk sprint updates in Jira sent sudden bursts of webhooks, overwhelming the backend processing thread.

Solution: Built asynchronous webhook ingest endpoints with payload validation and de-duplication, updating cached ticket states before persisting to database.
